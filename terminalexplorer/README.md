# Terminal Explorer

VS Code風の高機能ファイルエクスプローラー

## 概要

Terminal Explorerは、Windows ExplorerとVS Codeの操作性を融合した、Goで開発されたマルチプラットフォーム対応のファイルエクスプローラーです。

VS Codeのエクスプローラー＋統合ターミナル＋Git機能を、独立したファイルマネージャーとして再構築したアプリケーションを目指しています。

## 主な機能

### Phase 1 MVP（現在実装中）
- ウィンドウと基本レイアウト
- ツールバー（戻る、進む、上へ、更新、パス入力）
- ナビゲーションサイドバー
- ファイルエクスプローラー（ツリー表示/リスト表示）
- フォルダナビゲーション
- PowerShell統合ターミナル
- ターミナル表示/非表示切り替え
- エクスプローラーとターミナルの同期

### 将来的な機能
- 複数ターミナルタブ
- 複数エクスプローラータブ
- ファイル操作（コピー、移動、削除など）
- Git統合（ステータス表示、コミット、ブランチ管理など）
- ファイル検索
- コマンドパレット
- 設定画面
- ファイルプレビュー

## 技術スタック

- **バックエンド**: Go + Wails
- **フロントエンド**: React + TypeScript + Vite
- **ターミナル**: ConPTY (Windows) / PTY (macOS/Linux)
- **ファイル監視**: fsnotify
- **アイコン**: Lucide Icons

## 開発環境のセットアップ

### 前提条件
- Go 1.27.0以上
- Node.js 24.19.0以上
- npm 11.17.0以上

### インストール手順

1. リポジトリをクローン
```bash
git clone <repository-url>
cd terminalexplorer
```

2. Goモジュールの依存関係をインストール
```bash
go mod tidy
```

3. フロントエンドの依存関係をインストール
```bash
cd frontend
npm install
cd ..
```

## 開発モードでの実行

ライブ開発モードで実行するには、プロジェクトディレクトリで `wails dev` を実行します。

```bash
wails dev
```

これにより、フロントエンドの変更を非常に高速にホットリロードするVite開発サーバーが実行されます。

ブラウザで開発し、Goメソッドにアクセスしたい場合は、http://localhost:34115 で実行される開発サーバーもあります。ブラウザでこのアドレスに接続すると、デベロッパーツールからGoコードを呼び出すことができます。

## ビルド

再配布可能な本番モードパッケージをビルドするには、`wails build` を使用します。

```bash
wails build
```

## キーボードショートカット

### 基本操作
- `Ctrl + `` `: ターミナル表示/非表示
- `Ctrl + J`: ターミナル表示/非表示
- `Ctrl + T`: 新しいエクスプローラータブ
- `Ctrl + W`: タブを閉じる
- `Ctrl + Tab`: タブ切り替え
- `Ctrl + L`: アドレスバーにフォーカス
- `F2`: 名前変更
- `Delete`: 削除
- `F5`: 更新
- `Alt + ↑`: 親フォルダへ移動
- `Alt + ←`: 戻る
- `Alt + →`: 進む

### ツリー操作
- `→`: フォルダを展開
- `←`: フォルダを閉じる
- `Enter`: ファイルを開く/フォルダへ移動
- `Space`: 選択

## 開発方針

1. **Windows最優先**: Windowsを最優先として開発し、その後他のOSに対応
2. **段階的開発**: Phase 1 MVPから始まり、段階的に機能を追加
3. **パフォーマンス重視**: 大量ファイル対応、UIスレッドをブロックしない設計
4. **VS Code風デザイン**: ごちゃごちゃしていない、キーボード操作が快適なUI
